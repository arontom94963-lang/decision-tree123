Project Overview

What this notebook demonstrates

This project predicts a student's Final Mark from study habits, attendance, previous academic performance, assignments, sleep and participation using a Decision Tree Regressor.

Raw CSV→Clean→Format→X / y→Train/Test→Decision Tree→Evaluate→Predict
Purpose: The goal is not only to obtain a predicted mark, but to understand every stage of a regression machine-learning workflow. The tree learns simple if/then split rules from historical student records.

Data Cleaning

Fix missing values, spaces and duplicate rows
—Duplicate rows detected
—Blank / invalid cells detected
—Rows after cleaning
df = df.drop_duplicates() numeric_cols = [...] for col in numeric_cols: df[col] = pd.to_numeric(df[col], errors="coerce") df[col] = df[col].fillna(df[col].median())
What is happening? Duplicate observations are removed. Numeric fields are converted safely to numbers. Missing or invalid numeric values are replaced with the column median. This prevents simple data-quality problems from entering the model.
3

Data Formatting & Feature Preparation

Make columns consistent and model-ready

Numeric features

Study Hours, Attendance, Assignments Completed, Previous Score, Sleep Hours, Participation and Internet Usage Hours are numerical inputs.

Target

Final Mark is the numerical value the Decision Tree Regressor learns to predict.

numeric_cols = [ "Study_Hours", "Attendance", "Assignments_Completed", "Previous_Score", "Sleep_Hours", "Participation", "Internet_Usage_Hours" ] X = df[numeric_cols] y = df["Final_Mark"]
Purpose: A regression tree needs numerical values to compare thresholds such as Study_Hours ≤ 6.2. Unlike many algorithms, a decision tree does not require feature scaling for these inputs.

Train–Test Split

Keep unseen records for evaluation
80%Training data
20%Testing data
42Random state
from sklearn.model_selection import train_test_split X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, random_state=42 )
Purpose: Training data teaches the tree. Test data stays unseen during training and is used later to estimate how well the learned rules work on new records.
6

Build the Decision Tree Regressor

Learn if/then rules that predict a numerical mark
from sklearn.tree import DecisionTreeRegressor model = DecisionTreeRegressor( criterion="squared_error", max_depth=4, min_samples_leaf=8, random_state=42 ) model.fit(X_train, y_train)

A regression tree repeatedly chooses a feature and threshold that reduce the prediction error inside the child groups. A leaf predicts the average Final Mark of the training observations that reach that leaf.

Purpose: The tree visualization makes the model's logic visible. Follow a student's feature values from the root downward. When a condition is satisfied, follow the corresponding branch until a leaf gives the predicted mark.

Model Evaluation

Measure prediction error on unseen students
—MAE — average absolute error
—RMSE — typical error scale
—R² — explained variation
MetricMeaning
MAEAverage absolute difference between actual and predicted marks.
RMSESquare root of average squared error; larger errors receive more weight.
R²Proportion of test-set variation explained by the model relative to a mean-only baseline.
Purpose: Evaluation tells us how the trained tree performs on records it did not use for learning. Lower MAE/RMSE generally means smaller prediction errors; R² is interpreted in the context of the test set and model design.
